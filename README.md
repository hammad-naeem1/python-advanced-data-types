# Python Data Structures & Core Notes

This repository contains my personal notes, code snippets, and exercise solutions as I learn Python data structures, algorithms, and core language features.

## Project Overview

The goal of this repository is to build a solid technical foundation in Python through hands-on coding and structured learning. It acts as a reference log for built-in data types, standard libraries, and common problem-solving patterns.

## Contents

- Basic Data Types: Strings, Integers, Floats, Booleans
- Data Structures: Lists, Tuples, Dictionaries, Sets
- Control Flow: Conditional statements, For/While loops, List comprehensions
- Functions & Scope: Parameters, return values, Lambda expressions
- Object-Oriented Programming: Classes, inheritance, magic methods
- Standard Library: Math, Collections, Itertools, Sys, OS
